# Body sliders: how one 0..1 slider drives VaM (Genesis 2 Female) morphs. Source: docs/research/vam-body-sliders.md (table in section 1).
# Tab separated.  slider<TAB>name<TAB>default s   starts a slider;  morph<TAB>morph name<TAB>start<TAB>end   adds a morph to it:
# the morph's value is start + s * (end - start) (linear, reversed ranges allowed).
# The pipeline writes shape.<slider>.txt = sum over the morphs of (end - start) * (the morph's delta per unit value), transferred to her,
# and 'slider <name> <s0> <file>' in character.txt (s0: the slider position the VaM character is at). Morphs the export lacks are skipped (WARN).
# Not here: Skin Tone and Gloss (material scalars, not morphs); the Breasts slider's "pinned to 0 -> 0" morphs (no effect);
# the "Breast Under" slider moves Breast Height Lower only (as the research notes).
